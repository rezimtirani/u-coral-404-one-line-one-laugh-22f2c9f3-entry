One funny line, short enough to read in a breath: the Roomba that ran away from home and left a note behind.

> My Roomba ran away from home. It left a note: 'I found a house with fewer crumbs and more respect.'

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
